# 하천바람집 여행 지도

제주 표선 가족여행(10월, 11명) 때 쓰는 휴대폰용 지도 사이트입니다. 숙소 근처 식당과 가볼 만한 곳을 일러스트 지도와 목록으로 보여 줍니다. 가족은 로그인이나 비밀번호 없이 링크만으로 찾은 곳을 추가할 수 있고, 고른 종류(식당·카페·가볼 만한 곳)의 목록에 함께 보입니다.

- 사이트: https://amiable99.github.io/jeju-trip-map/
- 화면: `index.html` 한 파일입니다. 빌드 도구 없이 GitHub Pages로 배포합니다.
- 저장소: Google 시트(`places` 시트)입니다.
- API: Google Apps Script 웹 앱(`Code.gs`)입니다.

아래 1~4단계는 처음 한 번만 하면 됩니다.

## 1. Google 시트 만들기

1. https://sheets.new 에서 새 스프레드시트를 만듭니다. 이름은 예를 들어 `제주 여행 장소`로 합니다.
2. 아래쪽 시트 탭 이름을 `places`로 바꿉니다. 탭 이름은 꼭 이 이름이어야 합니다.
3. 1행 머리글은 직접 적지 않아도 됩니다. 첫 장소가 추가될 때 `id | createdAt | name | kind | link | memo | addedBy`가 자동으로 생깁니다.

## 2. Apps Script 붙여넣기

1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다. 시트에 연결된 스크립트여야 하므로 꼭 이 메뉴에서 여세요.
2. 편집기에 있던 `Code.gs` 내용을 모두 지우고, 이 저장소의 `Code.gs` 내용을 붙여넣은 뒤 저장(⌘S)합니다.

## 3. 웹 앱으로 배포하기

1. Apps Script 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(톱니바퀴)에서 **웹 앱**을 고릅니다.
3. 다음처럼 설정하고 **배포**를 누릅니다.
   - 설명: `v1`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. 처음에는 권한 승인 창이 뜹니다. **액세스 승인 → 내 계정 선택**을 누릅니다. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (안전하지 않은 페이지로) 이동 → 허용**을 누릅니다. 내가 만든 스크립트가 내 시트에 쓰도록 허락하는 것입니다.
5. 배포가 끝나면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. 브라우저에서 그 URL을 열어 `{"ok":true,"places":[]}`가 보이면 정상입니다.

## 4. 사이트에 API 주소 넣기

1. `index.html`에서 `const API_URL = '';`를 찾아 따옴표 안에 5번에서 복사한 URL을 넣습니다.
2. 커밋하고 `main`에 푸시합니다. 1~2분 뒤 사이트에 반영됩니다.

```bash
git add index.html
git commit -m "Apps Script API 주소 연결"
git push
```

## 5. 사이트 배포 (GitHub Pages)

이 저장소는 GitHub Pages(`main` 브랜치의 루트 폴더)로 이미 배포되어 있습니다. 새로 설정해야 할 때는 다음 순서로 합니다.

1. GitHub 저장소의 **Settings → Pages**를 엽니다.
2. Source를 **Deploy from a branch**, Branch를 `main` / `/ (root)`로 두고 **Save**를 누릅니다.
3. 1~2분 뒤 `https://amiable99.github.io/jeju-trip-map/`에서 열립니다.

`main`에 푸시하면 자동으로 다시 배포됩니다. 검색에 나오지 않도록 페이지에 `noindex`를 넣어 두었습니다. 다만 링크를 아는 사람은 누구나 볼 수 있습니다.

## 6. 가족에게 공유하기

사이트 링크를 단톡방에 보내면 됩니다. 비밀번호가 없어서 링크를 아는 사람은 누구나 장소를 추가하고 지울 수 있으니, 링크는 가족에게만 보내 주세요. 실수로 지운 장소는 시트의 **파일 → 버전 기록**에서 되살릴 수 있습니다.

## Code.gs를 고쳤을 때

**배포 → 배포 관리 → (연필) 수정 → 버전: 새 버전 → 배포**로 다시 배포합니다. 이렇게 하면 웹 앱 URL이 바뀌지 않아서 `index.html`을 고치지 않아도 됩니다. "새 배포"를 누르면 URL이 바뀌니 주의하세요.

## 확인 목록

- [ ] 휴대폰에서 가로 스크롤 없이 지도, 목록, 추가 폼이 보인다.
- [ ] 지도와 카드의 링크가 네이버 지도로 열린다.
- [ ] 장소를 추가하면 시트에 한 줄이 생기고, 새로고침해도 목록에 남아 있다.
- [ ] 빈 이름은 "장소 이름을 입력해 주세요.", `https://`가 아닌 링크는 "링크는 https:// 로 시작하는 주소를 붙여넣어 주세요."가 나온다.
- [ ] 삭제는 "지울까요? 지우기 / 취소"로 한 번 확인한 뒤 시트에서 지워진다.

## 장소 데이터

- 고정 장소(숙소 1곳, 식당 4곳, 가볼 만한 곳 2곳)는 `index.html`의 지도 SVG와 카드에 직접 들어 있습니다.
- 지도 좌표 변환식(viewBox 680×600)은 `x = 40 + (lon - 126.72) * 2500`, `y = 50 + (33.45 - lat) * 2975`입니다.
- 가족이 추가한 곳은 네이버 지도 링크(특히 앱의 "공유 → 링크 복사"로 만든 `naver.me` 링크)에서 Apps Script가 좌표를 찾아 시트의 `lat`, `lon` 열에 적습니다. 좌표가 있으면 숙소 주변 지도와 제주 전체 지도에 점으로 나옵니다. 못 찾으면 `lat`에 `-`가 적히고 목록에만 나옵니다.
- 제주 전체 지도 좌표 변환식(viewBox 680×420)은 `x = 21 + (lon - 126.14) * 760`, `y = 20 + (33.58 - lat) * 910`입니다. 해안선은 [southkorea-maps](https://github.com/southkorea/southkorea-maps)의 KOSTAT 2013 시도 경계를 단순화한 것입니다.
- 아직 확정하지 않은 후보 22곳은 `index.html`의 `CANDIDATES` 배열에 데이터로만 들어 있고, 화면에는 나오지 않습니다.
- 운영시간과 휴무일은 Google 데이터라 실제와 다를 수 있습니다.
